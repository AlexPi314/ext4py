# Проверка ext4py

Тесты используют стандартный модуль Python `unittest` и не требуют
дополнительных Python-пакетов. Все команды ниже выполняются из корня проекта.

## Запуск

Для запуска доступны следующие команды:

| Команда | Что делает |
| --- | --- |
| `make test` | Запускает тесты |
| `make check` | Проверяет компиляцию исходников, тестов и скриптов, а затем запускает тесты |
| `make coverage` | Запускает тесты и измеряет покрытие кода |

Если `make` не установлен, те же проверки можно выполнить напрямую:

```sh
python3 -m compileall -q src tests scripts
python3 -m unittest discover -s tests -v
python3 scripts/coverage.py
```

Для интеграционных проверок нужен `mke2fs` из e2fsprogs. Если он не установлен,
соответствующая группа тестов будет пропущена. Если доступен `e2fsck`, тесты
также используют его для подготовки индексируемых каталогов. Образы создаются
во временном каталоге, который удаляется после выполнения тестов. Права
администратора и монтирование не нужны.

Отчёты покрытия `.cover` и сводка `summary.json` сохраняются в `build/coverage/`.
Покрытие рассчитывается для пакета `src/ext4py`. В него не входят сами тесты,
вспомогательные скрипты и код, выполняемый в дочерних процессах.

## Создание тестового образа

Для проверки команд вручную можно создать небольшой образ с текстовым файлом.
В Linux с установленными e2fsprogs выполните из корня проекта команды ниже.
Если каталог `.demo/example` уже существует, замените его имя во всех командах,
чтобы не затронуть результаты предыдущего запуска.

```sh
mkdir -p .demo/example/root/docs
printf 'Тест EXT4\n' > .demo/example/root/docs/example.txt
truncate -s 64M .demo/example/disk.raw
mke2fs -q -F -t ext4 -b 1024 -d .demo/example/root .demo/example/disk.raw
./ext4py .demo/example/disk.raw ls /docs
./ext4py .demo/example/disk.raw cat /docs/example.txt
(cd .demo/example && ../../ext4py disk.raw cp /docs/example.txt)
(cd .demo/example && ../../ext4py disk.raw tar /docs)
cat .demo/example/disk.raw | ./ext4py - ls /
```

После выполнения команд в `.demo/example/` появятся извлечённый файл
`example.txt` и архив `docs.tar.gz`. Если повторить извлечение в тот же
каталог, программа завершится с ошибкой, поскольку она не перезаписывает
существующие файлы. Для повторной проверки используйте новый каталог.

Инструкция по использованию утилиты находится в [основном README](../README.md).
Методика испытаний, их результаты и ограничения описаны
в [отчёте](../docs/отчёт.docx).
