# Вспомогательные скрипты

В этой папке находятся скрипты для установки команды `ext4py` и измерения
покрытия кода тестами. Они используют стандартную библиотеку Python,
поэтому устанавливать дополнительные пакеты не нужно. Все команды ниже
выполняются из корня проекта.

## Установка команды

Чтобы установить утилиту в домашний каталог, выполните:

```sh
python3 scripts/install.py --prefix "$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"
ext4py --help
```

Параметр `--prefix` задаёт каталог установки. В примере модули программы
будут скопированы в `$HOME/.local/lib/ext4py`, а файл для запуска появится
по пути `$HOME/.local/bin/ext4py`. Если вы выберете другой каталог установки,
добавьте его подкаталог `bin` в `PATH`. Чтобы настройка сохранялась в новых
сеансах терминала, добавьте строку с `export PATH` в файл настройки оболочки.

Если по выбранному пути уже установлена программа, скрипт завершится
с ошибкой и не станет заменять файлы. Чтобы удалить установку из примера,
удалите файл `$HOME/.local/bin/ext4py` и каталог `$HOME/.local/lib/ext4py`.
При другом значении `--prefix` используйте соответствующие пути.

Устанавливать утилиту необязательно: из корня проекта её можно запустить
командой `./ext4py`.

## Измерение покрытия

Чтобы запустить тесты и узнать, какие строки кода они выполняют, используйте:

```sh
python3 scripts/coverage.py
```

Скрипт использует стандартный модуль `trace` и сохраняет построчные отчёты
`.cover` вместе со сводкой `summary.json` в каталоге `build/coverage/`.
Если нужен другой каталог, укажите его через `--output`:

```sh
python3 scripts/coverage.py --output build/coverage-custom
```

Если какой-либо тест завершится с ошибкой, скрипт вернёт ненулевой код
завершения. Требования к среде и порядок запуска проверок описаны
в [README тестов](../tests/README.md).

Инструкция по работе с самой утилитой находится
в [основном README](../README.md).
